# ADR-0001: k3s em EC2

## Status

Aceita.

## Decisão

Usar k3s single-node em EC2 como plataforma Kubernetes principal da demonstração.

## Consequências

- Mantém custo baixo para AWS Academy.
- Preserva a experiência Kubernetes exigida pela Fase 3.
- Evita a complexidade e o custo operacional de EKS para uma demo acadêmica.
